# Nova Strike

Offizielle Android-Downloads und deutsche Update-Notizen für Nova Strike.

## ⬇️ Aktuelle Version

[Direkter APK-Download](https://pbrosvsanubias-star.github.io/nova-strike-updates/)

Der QR-Code öffnet diese feste Adresse und fordert automatisch die APK der neuesten Veröffentlichung an. Falls dein Browser den automatischen Start blockiert, tippe dort auf „APK herunterladen“. Android bestätigt anschließend die Installation.

[Zur neuesten Veröffentlichung](https://github.com/pbrosvsanubias-star/nova-strike-updates/releases/latest)

Lade dort die Datei `Nova-Strike-<Version>.apk` herunter. Die passende Textdatei beschreibt die Neuerungen.

## 📲 Installation und Updates

- Android 8.0 oder neuer wird benötigt.
- Installiere die APK als Update über deine vorhandene Nova-Strike-App. Deinstalliere das Spiel vorher nicht, damit dein Spielstand erhalten bleibt.
- Android fragt nach deiner Bestätigung und gegebenenfalls nach der Erlaubnis für diese Installationsquelle.
- Für den Wechsel zur GitHub-Updatefunktion installierst du Version 1.40 einmal manuell. Danach kannst du neuere veröffentlichte Versionen mit dem Update-Button im Spiel herunterladen.
- Für den Download brauchst du kein GitHub-Konto.

Spielstände, Pilotenname und Rangliste bleiben lokal auf deinem Gerät gespeichert.

Dieses Repository dient der Veröffentlichung der Android-App und ihrer Update-Notizen.
